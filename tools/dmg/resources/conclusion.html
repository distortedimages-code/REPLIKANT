C'EST PRÊT !

L'appli REPLIKANT est dans Applications : le plus simple pour sampler (carte son et MIDI en direct).

Dans Logic, le plug-in est dans les effets audio (Audio Units > distortedimages), ou dans le slot d'instrument sous Effets contrôlés par MIDI. Dans Live : Réglages > Plug-ins > Réanalyser s'il n'apparaît pas.

Ensuite, les mises à jour se font depuis le plug-in : bouton MISE À JOUR en haut.
